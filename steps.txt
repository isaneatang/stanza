STANZA — DEPLOYMENT & DEMO STEPS (BOT Chain Testnet)
=====================================================

PART 1 — PREPARE A WALLET
-------------------------
1. Install MetaMask (or any EVM wallet) if you don't have one.
2. Add the BOT Chain Testnet network manually:
       Network name : BOT Chain Testnet
       RPC URL      : https://rpc.bohr.life
       Chain ID     : 968
       Currency     : BOT
       Explorer     : https://scan.bohr.life
3. Go to the faucet: https://faucet.botchain.ai/basic
   Claim test BOT (for gas) AND test USDT (for tipping).
4. Export your account's PRIVATE KEY:
       MetaMask -> Account details -> Show private key -> copy it.
   Use a throwaway/dedicated account — never a key that holds real funds.


PART 2 — DEPLOY THE CONTRACT
----------------------------
(From the poetry-archive/contracts/ directory)

5. Install dependencies (once):
       npm install

6. Create your env file:
       cp .env.example .env
   Then edit .env and set:
       DEPLOYER_PRIVATE_KEY=0x...        <- the key from step 4
       PLATFORM_FEE_RECIPIENT=0x...      <- optional; defaults to deployer
                                            (this wallet receives the 3% tip fee)

7. Deploy to testnet:
       npm run deploy:testnet

8. COPY THE OUTPUT LINE:
       PoetryArchive deployed to: 0x<ADDRESS>
   Save this address — the frontend needs it in Part 3.

9. Sanity-check it on the explorer:
       https://scan.bohr.life/address/0x<YOUR_CONTRACT_ADDRESS>


PART 3 — RUN THE FRONTEND
-------------------------
(From the poetry-archive/web/ directory)

10. Install dependencies (once):
        npm install

11. Create your env file:
        cp .env.example .env.local
    Then edit .env.local and set:
        VITE_CONTRACT_ADDRESS=0x<ADDRESS FROM STEP 8>
        VITE_REOWN_PROJECT_ID=<optional — get one free at reown.com;
                               only needed for WalletConnect/mobile QR.
                               MetaMask-in-browser works without it.>

12. Start the dev server:
        npm run dev
    Open http://localhost:5173


PART 4 — DEMO WALKTHROUGH
-------------------------
13. Click "Connect Wallet" (top right) and connect the SAME account
    you deployed with (or any testnet-funded account).

14. If the "Wrong network" screen appears, click the switch button.

15. Claim a username:
        Write page -> "Claim your name" (or go to /claim).
    Pick something like verse_wright. Confirm the tx in your wallet.
    This is permanent — one name per address, forever.

16. Post your first poem (/post):
        Title optional, text required, pick a license, hit
        "Post permanently". Watch the optimistic pending card on the
        feed resolve ~1 second later (sub-second finality).

17. Tip flow (needs TWO accounts):
        - Import a second funded testnet account into your wallet.
        - Connect as account B, open account A's profile or any of
          A's poems, choose USDT or BOT, pick an amount, Tip.
        - First USDT tip triggers an Approve tx, then the tip tx.
        - The floating "+X USDT" animation confirms the send.
        - Check the fee split on the explorer: author gets 97%,
          PLATFORM_FEE_RECIPIENT gets 3%.

18. Open the Live view (/live):
        Block ticker + decoded PoemPosted / PoemTipped /
        UsernameClaimed events streaming in real time. Great for
        hackathon demos — do actions in another tab and watch them
        land here instantly.


QUICK TROUBLESHOOTING
---------------------
- "Chain data unavailable" banner on the feed
    -> VITE_CONTRACT_ADDRESS is missing/wrong in web/.env.local.
- Tip button does nothing / says connect
    -> Connect wallet first; self-tipping is blocked by design
       (tip someone else's poem).
- "Duplicate content already posted"
    -> Exact same text was posted before — change a word. By design.
- USDT tip fails with insufficient allowance
    -> Send the tip again; approval is requested automatically first.
- No test USDT after faucet claim
    -> Re-run the faucet; check your address on scan.bohr.life.
- Contract deploy fails with nonce/balance errors
    -> Make sure the account has test BOT for gas (faucet step 3).
